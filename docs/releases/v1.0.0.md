第一个公开发布的版本：在 Mac 上写 Hexo 博客、看主题的真实效果、管理图片和配置、一键部署。

### 写作与预览
- 文章 / 草稿列表与搜索；Markdown 编辑器带格式工具栏和常用快捷键，自动保存
- 文章信息（front-matter）单独一块显示在正文上方，日期、标签、分类用专门的控件，只改动改过的字段
- 内嵌 `hexo server --draft` 的主题真实预览，保存后自动刷新并回到原来的位置；预览页可以单独启动、停止

### 图片
- 图片库按项目统一管理，阿里云 OSS / S3 兼容存储，可建多套存储配置随时切换
- 导入面板：把图片拖进窗口、按 ⌘V 粘贴截图、或选择文件，先在面板里看压缩、WebP 转换的效果，改名、填描述后再上传；在编辑器里上传完直接插入文章，其他地方把地址复制到剪贴板
- 接管旧图、检查图片能否访问、查看每张图被哪些页面使用、导入导出核对清单

### 配置
- 配置页：站点 `_config.yml`、主题配置、插件、`source/_data` 页面数据都能看、能改，保留注释和原有写法，标出与主题默认不同的值
- 安知鱼主题的常用分组有专门的控件：导航菜单、评论与搜索服务、侧栏卡片、图片字段接图片库

### 源码与部署
- 源码页：git 改动、提交（标题与说明分开）、推送、拉取，点历史提交直接看改了哪些文件
- 部署页：清理、生成、部署，日志高亮，识别 GitHub 推送保护等常见问题并给出处理办法

### 新建博客
- 欢迎页“新建博客…”：纯 Hexo（与 `hexo init` 相同），或从模板新建（目前有安知鱼），显示模板的作者、许可、官网、文档和仓库；建好直接打开

### 用户、设置与主题
- 侧栏左下角是用户面板（头像、名字），齿轮进入设置；设置分为用户、编辑器、项目、Node、关于
- 外观可选“默认”或“VS Code”主题，各有浅色和深色
- 偏好跟着用户只存在本机，从旧版本升级时自动迁移；博客的存储配置仍随博客保存在 `.hexostudio/`
- “关于”里可以检查更新、查看更新日志

### 说明
- 仅支持 Apple Silicon 的 Mac；应用没有经过 Apple 公证，第一次打开请在“应用程序”里右键选“打开”
- 需要本机装有 Node.js；新建博客装的是最新的 Hexo，需要 Node 20.19 以上
