写作体验的改进：外部改动不再撞车，预览可以边写边看，VS Code 主题更紧凑。

### 写作
- 用别的编辑器或 git 改了文章，文章列表会自己刷新
- 正在编辑的文章被别处改动时：没有未保存的修改就直接载入新内容；有的话停下自动保存，让你选“重新载入”还是“保留我的版本”；文章被删除或改名时可以按自己的版本重新保存
- 载入新内容时光标和滚动位置保持不动
- 预览栏右上角可以切换“主题 / 即时”：即时预览不经 Hexo、不必保存，边写边显示渲染后的 Markdown；主题的图片标签画成图片，其他标签插件只标出名字，真实样子切回“主题”看

### 外观
- VS Code 主题的按钮、输入框、导航和列表行更紧凑，更接近 VS Code 本身；默认主题不变
