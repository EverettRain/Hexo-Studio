第一个版本。

- 欢迎页：最近打开的博客、打开博客文件夹、检查更新；每个博客在自己目录下有 `.hexostudio/`
- 写作：文章 / 草稿列表与搜索，front-matter 表单（只改动改过的字段，其余原样保留）+ Markdown 编辑器，自动保存
- 预览：内嵌 `hexo server --draft` 的主题真实效果，保存后自动刷新并回到原来的滚动位置
- 部署：清理、生成、部署（与 `hexo clean && hexo generate && hexo deploy` 相同），新建文章 / 草稿、发布草稿；日志高亮，识别 GitHub 推送保护（GH013）并给出放行链接
- 图片：阿里云 OSS / S3 兼容存储；粘贴、拖入或选择图片即上传并插入，默认转 WebP（可选原图），原图先存一份到本机；旧图一键迁移到 `<项目名>/<页面名>/` 并改写博客里的地址
