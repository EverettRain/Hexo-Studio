第一个版本。

- 欢迎页：最近打开的博客、打开博客文件夹、检查更新；每个博客在自己目录下有 `.hexostudio/`
- 写作：文章 / 草稿列表与搜索；Markdown 编辑器带格式工具栏与常用快捷键（标题、加粗、列表、代码块、表格、链接、主题标签插件），状态栏显示字数；文章信息（front-matter）写在文章开头、随正文滚动，日期、标签、分类用自带的日历和标签块控件（只改动改过的字段，其余原样保留）；正文里的图片显示为缩略图和名称，点一下可切换主题图片标签 / Markdown / 行内写法、设宽高和说明；自动保存
- 预览：内嵌 `hexo server --draft` 的主题真实效果，保存后自动刷新并回到原来的滚动位置
- 部署：清理、生成、部署（与 `hexo clean && hexo generate && hexo deploy` 相同），新建文章 / 草稿、发布草稿；日志高亮，识别 GitHub 推送保护（GH013）并给出放行链接
- 图片：阿里云 OSS / S3 兼容存储，可以建多套存储配置（桶、密钥、上传格式、插入写法成套保存）在图片页随时切换；粘贴、拖入或选择图片即上传并插入，默认转 WebP（可选原图），原图先存一份到本机；旧图一键接管进图片库并改写博客里的地址
- 图片库：按项目统一管理（对象名 `<项目名>/<内容哈希>.webp`），图片页浏览、检查、编辑名称与位置描述、看每张图被哪些页面使用；文章里从图库取图或设为封面；导入 / 导出图片核对清单 CSV
